# weather_forecast

## Mục đích
Lấy thông tin thời tiết hiện tại tại một địa điểm bất kỳ, sử dụng API wttr.in (được trả về định dạng text/JSON).

## Khi nào dùng
- Khi người dùng hỏi "Thời tiết ở X hôm nay thế nào?"
- Cần lấy nhanh nhiệt độ, mô tả thời tiết mà không cần web search.

## Lưu ý
- Địa điểm có thể là tên thành phố, hoặc để trống (lấy IP hiện tại).
